# Originalbilder

Hochaufgelöste Originale (empfohlen 2400 × 1600 px, 3:2, JPG oder PNG) für KI-generierte und eigene Bilder.
Sie werden nicht veröffentlicht; `npm run bilder` erzeugt daraus die Webdateien in `public/bilder/<ordner>/`.

- `kompetenzen/` – Kopfbilder der Kompetenzseiten, Dateiname = ID der Kompetenz,
  z. B. `tiefbau-infrastruktur.jpg`

Prompts, Zuschnitt und Alternativtexte: [docs/BILDKONZEPT.md](../docs/BILDKONZEPT.md).
